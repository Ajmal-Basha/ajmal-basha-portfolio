AJMAL BASHA — PERSONAL PORTFOLIO
================================

PROJECT STRUCTURE
- index.html       Home page
- skills.html      Technical skills
- projects.html    Featured projects
- education.html   Education
- personal.html    Personal information
- css/style.css    All styling and responsive layouts
- js/script.js     Mobile navigation and footer year
- assets/          Profile image placeholder

HOW TO RUN
1. Extract the ZIP file.
2. Open the folder in VS Code.
3. Open index.html in your browser (or use the VS Code Live Server extension).
   No build tools, package installation, or framework is required.

CUSTOMIZE BEFORE PUBLISHING
1. Your profile photo is already added at assets/profile.jpg.
2. In personal.html, replace "Add your email address" and
   "Add your city / address" with the information you want to publish.
3. Verify your LinkedIn and GitHub profile URLs.
4. Check the education details and update if anything has changed.
5. Update project descriptions and technologies to match the actual repositories.

TECHNOLOGIES
HTML5, CSS3, basic vanilla JavaScript only.
Google Fonts is loaded online; the site still works without it using fallback fonts.
